GPC SHI - สร้างเป็นโปรแกรม .exe บน Windows
=========================================

สิ่งที่ต้องมี
- Windows 10 หรือ 11
- Node.js (เวอร์ชัน LTS) ดาวน์โหลดที่ https://nodejs.org
- อินเทอร์เน็ต (ใช้ตอนสร้างโปรแกรมครั้งแรก)

วิธีสร้างโปรแกรม
1) แตกไฟล์ zip นี้ไว้ที่โฟลเดอร์ใดก็ได้ (เช่น เดสก์ท็อป)
2) ดับเบิลคลิก build.bat แล้วรอประมาณ 3-10 นาที
3) เมื่อเสร็จ จะมีโฟลเดอร์ dist\GPC SHI-win32-x64
   ดับเบิลคลิก "GPC SHI.exe" ในโฟลเดอร์นั้นเพื่อเปิดโปรแกรม
4) จะส่งให้คนอื่น ให้บีบอัด (zip) ทั้งโฟลเดอร์ "GPC SHI-win32-x64" ส่งไป
   ปลายทางแตกไฟล์แล้วเปิด GPC SHI.exe ได้เลย ไม่ต้องติดตั้ง Node.js

อยากได้ตัวติดตั้ง (Setup.exe) แบบมีทางลัดบนเดสก์ท็อป
- คลิกขวา build-installer.bat เลือก Run as administrator
- ตัวติดตั้งจะอยู่ที่โฟลเดอร์ dist-installer

อยากลองเปิดดูก่อนสร้าง .exe
- ดับเบิลคลิก run-test.bat

ข้อควรรู้
- รูปและปกที่ตั้งไว้ จะเก็บในเครื่องที่ใช้โปรแกรม (ไม่ซิงก์ออนไลน์)
- ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์และปกแมพเกม
- กด F11 เพื่อสลับเต็มจอ
- ถ้า Windows ขึ้นหน้าต่าง SmartScreen เพราะโปรแกรมไม่มีลายเซ็นดิจิทัล ให้กด
  "ข้อมูลเพิ่มเติม" แล้วเลือก "เรียกใช้อยู่ดี"
